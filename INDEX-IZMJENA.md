# Favicon - izmjena index.html

Unutar `<head>` u korijenskom `index.html` dodajte ili zamijenite favicon retke:

```html
<link rel="icon" type="image/png" sizes="32x32" href="/images/logo/favicon-32.png" />
<link rel="icon" type="image/png" sizes="192x192" href="/images/logo/favicon-192.png" />
<link rel="apple-touch-icon" sizes="512x512" href="/images/logo/favicon-512.png" />
```
